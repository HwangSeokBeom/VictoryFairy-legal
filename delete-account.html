계정 및 데이터 삭제 안내

승리요정에서 사용자의 기록과 설정을 삭제하는 방법을 안내합니다.

최종 업데이트: 2026년 8월 15일

회원가입 없이 사용하는 방식

승리요정은 이메일이나 소셜 계정으로 가입하지 않습니다. 앱이 생성한 임의의 기기 식별자로 서버의 기록·설정·프로필을 구분합니다.

개별 기록과 프로필 이미지 삭제

직관 기록은 앱의 해당 기록 화면에서 삭제할 수 있습니다. 서버 연결이 정상인 경우 앱과 서버의 해당 기록이 함께 삭제됩니다. 프로필 이미지는 프로필 설정에서 삭제할 수 있습니다.

서버 데이터 전체 삭제 요청

  1. tjrqja07@icloud.com으로 제목을 “승리요정 서버 데이터 삭제 요청”이라고 적어 보내 주세요.
  2. 본인 데이터를 찾을 수 있도록 앱에서 사용한 닉네임, 응원 팀, 최근 직관 기록의 대략적인 날짜 중 가능한 정보를 적어 주세요. 비밀번호, 주민등록번호, 신분증 사본은 보내지 마세요.
  3. 운영자는 타인의 데이터가 삭제되지 않도록 필요한 최소 범위에서 추가 확인을 요청할 수 있습니다.
  4. 확인이 끝나면 처리 결과를 회신합니다. 특별한 사유가 없는 한 요청 접수 후 10일 이내 처리를 목표로 합니다.

전체 삭제 대상

  • 기기 식별자에 연결된 직관 기록, 일기, 메모, 좌석·동행 정보와 태그
  • 응원 팀·주 관람 구장 등 서버 설정
  • 닉네임, 응원 팀, 프로필 이모지, 공개 작성자 식별자와 프로필 이미지
  • 커뮤니티 기능을 사용한 경우 게시물, 신고 및 차단 정보

앱 삭제 시 유의사항

앱을 삭제하면 기기에 저장된 사진·설정과 앱의 기기 식별자가 제거될 수 있지만, 서버에 이미 저장된 기록과 프로필은 자동으로 삭제되지 않습니다. 앱을 삭제하기 전에 위 절차로 서버 데이터 삭제를 요청해 주세요. 앱을 다시 설치하면 새로운 기기 식별자가 발급되어 이전 서버 데이터를 앱에서 찾기 어려울 수 있습니다.

제한적 보관

삭제 요청이 완료되더라도 법령 준수, 보안, 부정 이용 방지 또는 분쟁 대응을 위해 필요한 최소 정보는 해당 목적에 필요한 기간 동안 분리 보관될 수 있습니다. 백업에 남은 정보는 백업 순환 주기에 따라 파기되며 복구 목적 외에는 이용하지 않습니다.
