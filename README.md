# VictoryFairy Legal Pages

Static GitHub Pages site for the VictoryFairy iOS app, also known as 승리요정 직관일기.

## Purpose

This repository hosts legal, privacy, support, account/data deletion, disclaimer, and community policy pages for VictoryFairy. The site is plain HTML and CSS with no build system, analytics, tracking scripts, or external API calls.

## GitHub Pages URL

https://hwangseokbeom.github.io/VictoryFairy-legal/

## File List

- `index.html` - Home and policy/support links
- `terms.html` - Terms of use
- `privacy.html` - Privacy policy
- `support.html` - Support and FAQ
- `delete-account.html` - Account and data deletion guide
- `disclaimer.html` - KBO affiliation and feature disclaimer
- `community-policy.html` - Community handling policy
- `styles.css` - Shared responsive styling
- `README.md` - Project documentation

## How to Edit

Edit the HTML files directly for page content. Edit `styles.css` for site-wide visual changes. The public support contact is `tjrqja07@icloud.com`; update all pages together if it changes.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to Settings -> Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `master` or `main`.
5. Select `/root`.
6. Save the settings.

## Important Warning

Do not commit secrets, API keys, or user data.
